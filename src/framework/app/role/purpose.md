Provides a Role construct. A Role is a container of features owned by an Application. Each Application has 1 Role. A Role can have many features. Role is intended as a base for customization and reuse. For example a ConsoleAppRole derived from Role might have Features for Console and FileSystem integration built in. Roles can also be customized at runtime by adding features. Features are started up in the order they were added, when the owning application is run and shutdown, in reverse order, when the application exits.
