Provides external polymorphism tools to augment plain type without modifying them.

Attach custom interfaces to a type which survive extension of the underlying type but are type safe.
Outbound adapters and inbound ports that can modify the adapted type contents
Arbitrary meta data attachment and any level of validation, change notification, interception can be added as needed
Low level operation are all agnostic of the containing type so they can be reused on multiple interfaces
Any number of interfaces per data type, no cross cost.
