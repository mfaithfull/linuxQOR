# U5 register entry (verbatim)

- **U5 CLOSED 10 Nov 2026 by user decision **D36** (`docs/agent/DECISIONS.md`): accepted as by design, no code change.** The one-time resolution is the design: `kernel32.h:75` makes the whole `GetModuleHandle` + `GetProcAddress` pair the initialiser of a function-local `static const Library::DefProc`, so a wrapper pays it once per process, and the AW forms at `:77`/`:79` share it. Caching a failure with it is the same property, and it is not swallowed - a null binding throws at `library.h:50`-`53` (`Call`), `:72`-`85` (`voidCall`) and `:115`-`118` (`varCall`) before any call is made, so the verdict is the same for the whole lifetime rather than racing module loading. The measured item below is frozen history - append nothing (protocol 7).

- **U5 - the binding is cached for the process lifetime including failure.** `qor_pp_useswinapi` expands to
  a function-local `static const Library::DefProc pFunc = ...`; the first call wins forever. A process that
  has not mapped `user32.dll` yet (G5), is poisoned permanently.
