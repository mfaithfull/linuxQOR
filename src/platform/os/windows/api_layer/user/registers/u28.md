# U28 register entry (verbatim)

- **U28 - four wrappers bind entry-point names that exist only in the 64-bit `user32.dll` image.** Opened 4 Nov 2026
  (session 34, `windowclass.cpp`); **recorded, not fixed** - latent on every target that builds today, because x86 does
  not build at all (session 31: 93 of 106 `api_layer` TUs fail at `kernel32.h:92`, `registers/u6.md`), and the fix is an
  arch-conditional binding, which belongs with that blocker rather than with a TU pass.
