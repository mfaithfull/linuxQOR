# U7 register entry (verbatim)

- **U7 - SEH faults are swallowed into a default return.** `Call` catches everything and returns `ret _{}`
  (`library.h:54-62`), i.e. `0`/`nullptr`, which for most of this library is indistinguishable from a
  legitimate zero (see U2). The `serious(...)` report is the only trace. `voidCall` swallows without even a return
  value (`:74-80`). Citations re-measured 1 Nov 2026 after the U6 fix added 13 lines to `library.h` (they read
  `library.h:62-70` before, which did not match the file even then).
