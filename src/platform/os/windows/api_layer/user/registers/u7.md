- **U7 CLOSED 10 Nov 2026 by user decision **D35** (`docs/agent/DECISIONS.md`): accepted as-is, no code change.** The swallow at `library.h:61` (`Call` `:44`-`63`) and `:74`-`80` (`voidCall`) is reached only after `ExceptionFilterFunction` has raised the fault through `serious(...)` = `issue<Serious>(...)` = `new_ref<Serious>(...)->Handle()`, which either resolves it through the caller's own handler (so the caller already knows the call failed and ignores the value) or, unresolved, escalates and terminates the process (`docs/issues.md:24`, `fatal.cpp:45`) before the default value is observed. A fault is therefore never silently mistaken for a legitimate zero; distinguishing it is a caller-side responsibility, not a defect in this layer.
