# D28 - T9 step 9b: the 7 Raw Input members wrapped in `rawinput.cpp`, `static` on all 7 declarations - ACTION (9 Nov 2026)

The decision, from `docs/agent/decisions/D28.md`: step 9b of the D26 tranche queue in 9a's shape -
the new TU `src/platform/os/windows/api_layer/user/rawinput.cpp` defines **all 7** members of
`user32.h:543-549`, the header gains `static` on all 7 declarations and nothing else, and
`CMakeLists.txt` goes 48 -> 49.

- Binding is the exact mirror of D27's 9a: 6 bare `qor_pp_useswinapi` plus the one **mandatory**
  `qor_pp_useswinapiAW(user32, GetRawInputDeviceInfo)` D26 named in advance - the stem is `#undef`'d
  at `user32.h:16`, the export table has **no** `GetRawInputDeviceInfo` row (only A/W at 1B7/1B8), so
  a bare binding would stringize a name the DLL never exported and cache a NULL `pFunc` (G2 + G5);
  the other 6 have no A/W sibling, so AW would bind them to non-existent `...W` exports. `cl /EP`
  resolves 8 `GetProcAddress` sites, 7 of them this TU's; the 8th is the inherited `wsprintfW`
  header-inline member from `user32.h:840` (D20).
- Availability and signatures need no header work beyond `static`: all 8 prototypes sit at depth 3 in
  `um\WinUser.h`, **outside** the `#ifndef NOUSER` region (unlike 9a's 34), and D21's `0x0A00` pin
  satisfies the `>= 0x0501` guard; `PCRAWINPUTDEVICE` already carries its const in the type, so no
  U23-style move is owed.
- Return conventions: 6 numeric + 1 `BOOL`; the session-27 soundness test bars a zero-check at all 6
  numeric members because 0 is a legal count, and the one unambiguous `FALSE` (`RegisterRawInputDevices`)
  is unreachable without a `GetLastError` pass-through - so values come back as the OS wrote them,
  which is what keeps a swallowed SEH fault indistinguishable (U1/U2/U7).
- Consumers: 0 call sites through the layer; `_tmp_bypass_scan.ps1` reads exactly **1 live bypass** -
  `RegisterRawInputDevices` at `ui/gl/windowimpl.cpp:291` reaching the SDK import thunk (the
  textually identical call at `:280` is dead inside a block comment) - recorded, not moved, because
  `registers/u19.md` is frozen. Census: static 582 -> 589, the declared-and-undefined scan 18 -> 11,
  coverage stays 759 of 1,018 (a link gap closed, never a coverage gap); gate legs standalone exit 0,
  folder 49/49 clean, `/EP` 7 literals, all-libraries diff 116 -> 117 exit 2 both sides. A record
  defect was corrected on the way: `status.md`'s queue table was missing `security.cpp`'s row.
