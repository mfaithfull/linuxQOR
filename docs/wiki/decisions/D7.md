# D7 - ctags availability - RESOLVED

The decision, from `docs/agent/decisions/D7.md`: Universal Ctags 6.1.0 **is** on the box (installed
via WinGet); the executable is `ctags.exe`, so an earlier `where.exe ctags` probe missed it, but
`Get-Command ctags.exe` resolves it and `--version` confirms `Universal Ctags 6.1.0`. The corrected
rule: use ctags to index **every** lib, any size - no hand-indexing; a canonical per-lib command is
recorded in the entry.

- The entry's title says it "supersedes" an earlier hand-index assumption - but that assumption was
  never a ledger D-entry, so the probe measured **no ledger supersession** and this page carries no
  legal `SupersededBy:` field; the reversal is stated here in prose.
- The availability fact is about the machine, not this tree, so under D56 it is a sentinel page:
  the `--version` line is provenance for the decision, not a judge the wiki can re-run against a
  build.
- Stale when the toolchain moves (ctags absent or downgraded) - a box fact, checked by hand, which
  is exactly why it cannot be a commit-pinned claim about the repo.
