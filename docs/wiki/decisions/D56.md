# D56 - Wiki schema: sentinel judge line for not-command-falsifiable pages - GOVERNANCE (18 Nov 2026)

The decision, from `docs/agent/decisions/D56.md` (18 Nov 2026): a wiki page whose claim is **not falsifiable
against a build** carries `Judges: none - <reason>` as its single judge line instead of a command. The
required-field rule (`WikiPageRequiredFields`, `tools/wiki-census/wiki-shape.ps1:43`) asks for a **non-empty**
`Judges:` list; the sentinel names in its own reason why nothing can make the page red.

- **Measured basis**: the DecisionPages probe (55 of 55 commit anchors green) found **20 of 55** D-entries
  name **no command at all** - policy and process verdicts; inventing a judge is the one thing the wiki's
  falsification design forbids. The Concept pages item carried the same block from its creation.
- **The rule, pages only - 0 instruments changed**: command-bearing pages (module, gotcha, invariant, the 35
  decision pages with recorded verification lines) keep real commands; command-less decision pages use
  `none - policy verdict, no artifact ...` with the commit anchor as their falsification; concept pages use
  `PageType: concept` (not prose `Type: wiki-concept`, which would make the file a stray) plus the sentinel
  and the "describes a domain, not this tree" sentence.
- **No freshness special case**: schema lint accepts the sentinel (non-empty list), and freshness leaves such
  pages `undated` by design - a page nothing dates is a page nothing can stale-date.
- **What would make the sentinel a lie**: any entry that **does** name a buildable artifact or command must
  use the real command; the DecisionPages probe slot is the list of which is which.
- **0 files under `docs/wiki/` and 0 instruments changed by this entry** - it unblocks, it does not
  implement; after it the DecisionPages pass has no remaining blocker and Concept pages can be cut and run.
- Stale when a sentinel page gains a falsifiable artifact, or an instrument edit changes the rule.
