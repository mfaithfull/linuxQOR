# D38 - U8: null-binding report moved out of line plus explicit default returns - ACTION (10 Nov 2026), CLOSES U8 AND U29

The decision, from `docs/agent/decisions/D38.md` (user, 10 Nov 2026, `src/platform/os/windows/api_layer/library.h`,
one file): D37's inline `serious("Missing library function.")` inside each `__try` function is moved **out of
line** - new member `ReportMissingLibraryFunction()` at `library.h:30`-`33` - and the two value-returning null
sites (`Call` `:57`-`59`, `varCall` `:124`-`126`) get `ret _{}; return _;`, closing U8 and U29.

- **Measured: C2712 is gone.** The flyer's `std::string` and its unwind entry now live in a function with no
  `__try`: folder gate (54 sources) **exit 0**, 54 TU lines, 0 C2712; all-libraries gate (122 sources) exit 2
  with a **ZERO diff** against the recorded baseline - the baseline's lone `C1083` at `opengl\wgl.cpp:31` and
  165 warnings unchanged, against D37's failing run's 1,088 log lines. The diff, not the exit code, is the
  signal; the folder's own gate is the only one that must be 0, and it is.
- **The null pointer is never called through** - the entry's `/Fa` listing of all three shapes shows the null
  path calling the report then returning the default (`mov DWORD PTR _$1[rsp], 0`, `jmp` epilogue); the
  indirect `call QWORD PTR FP$[...]` sits only on the non-null path.
- **D35's premise is restored**: with the explicit returns, the default value at `Call:68`-`69` /
  `varCall:135`-`136` is reached only from the `__except` swallow, so D35's accepted-as-is reading still holds.
- U8's substance delivered: the null-binding report goes through the QOR issue facility - `serious` =
  `issue<Serious, const std::string&>` - instead of a bare `const char*` throw nobody catches; the terminal
  consequence (unresolved flyer escalates) is unchanged, now logged. The member is in-class, hence implicitly
  inline: no ODR change across 122 sources, **no published mangled name moves**.
- What it does not touch: `ExceptionFilterFunction`, the `__try`/`__except` shapes, the `__stdcall`/`__cdecl`
  spellings (U6/D21), the inline-call variants (D11), U2's accepted-as-is (G6), U5's cached-binding design
  (D36) - a null binding is still cached and still reports on every call, now as a flyer.
- Stale when `library.h` no longer carries the out-of-line report, a null site loses its explicit return, or
  the folder gate reads C2712 again.
