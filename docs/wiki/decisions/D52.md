# D52 - U2 verdict side: the decision process run over all 597 sites, NO CODE CHANGE (12 Nov 2026), U2 still OPEN

The decision, from `docs/agent/decisions/D52.md` (12 Nov 2026): the table gets a verdict for **every** site,
and the verdicts become the authority for the code side - a later batch edits from the recorded verdict rather
than from a page re-read at edit time.

- **Measured**: 597 of 597 rows in `tmp/_tmp_u2_endpoint_table.csv` carry `verdict / checkClass / docQuote` -
  **checked 352 / unchecked 236 / void 9** (sum 597, audit `fail=0`); per-region counts agree with the U1
  tree's `BatchSmallTUs` 124 / `BatchLargeTUs` 468 boundaries; `docQuote` holds the Microsoft page's verbatim
  Return value text on 596 rows, suffixed-twin (`...a`/`...ex`) pages fetched where load-bearing.
- **The unchecked majority is examined, not skipped**: each of the 236 rows carries its written reason -
  answer-shaped `BOOL`, zero-is-legal counts/positions, NULL-is-legal handles, previous-state returns - where
  a check would report a legal answer as a failure, which is what the 29 Oct leave-as-is protects.
- **Arbitrations recorded**: `SendMessage` unchecked vs `SendMessageTimeout` checked; `IsImmersiveProcess`
  unchecked vs `SetProcessRestrictionExemption` checked; `GetMessage` at `TCheckFailureValue< BOOL, -1 >`
  (zero is the legal `WM_QUIT`); `RegisterWindowMessage` at `TRangeCheck< UINT, 0xC000, 0xFFFF >`.
- **Does not**: land code (the code side continues in D53/D54), close U2, or touch `returncheck.h`,
  `user32.h`, banners or the D35/D50 escalation path.
- Stale when the code side lands verdicts that contradict a table row, or U2 closes with a different split.
