# D54 - U2 large-TU code region: 473 sites over 20 TUs land from the table - CODE CHANGE (12-13 Nov 2026), U2 stays OPEN

within the batch, and **only from the table**. `LargeTUBatchRegionChecks` (58 Atomic leaves, each at most 10

sites before its token lands, because G6 makes the check live on every call.
