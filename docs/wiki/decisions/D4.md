# D4 - now.md re-read every turn

The decision, from `docs/agent/decisions/D4.md` (a user directive): re-read
`memory-bank/now.md` every turn - it prevents context overflow on a 250k-LOC codebase.

- This is the purest sentinel case in the ledger: the rule constrains the **agent loop**, not the
  tree, so no command exists that could falsify it; D56's sentinel names that openly.
- Its only observable artifact is the habit - a session that acts on stale context has violated
  it, and nothing in `docs/wiki/` can see that.
- Stale when the memory-bank layout it depends on changes - e.g. if `now.md` is renamed
  or merged, the rule's referent is gone.
