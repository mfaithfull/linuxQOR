# D40 - U17: the 9 A/W members without the T suffix are renamed to SDK stem + T - ACTION (10 Nov 2026), CLOSES U17

The decision, from `docs/agent/decisions/D40.md` (user, 10 Nov 2026): **Option A - rename**, not the
accept-as-is Option B U4/U5/U7/U10 took. `MessageBoxTimeout` -> `MessageBoxTimeoutT` and eight more join the
norm the other 110 A/W members follow; U17's finding was a **naming** deviation, not missing implementations.

- **Why it is symbol-neutral** (measured before the edit): `qor_pp_useswinapiAW` at
  `api_layer/kernel/kernel32.h:77`/`:79` pastes `_NAME##W`/`_NAME##A` from its second argument - the **SDK
  stem** - so the binding literals must NOT move (pasting `T` into a literal would ask for
  `MessageBoxTimeoutTW` and throw); all 9 bare stems read **0 export rows** while every A/W row exists, so no
  bound symbol or mangled import name moves.
- **Published-surface change, accepted**: `User32` is a `QOR_WINAPIUSER` module interface (`user32.h:70`), so
  the 3 `ui/` call sites are in scope and all three were moved - the folder gate alone cannot prove the pass.
- **The pass**: 9 declaration renames, 9 definition heads in 8 TUs, 3 `ui/` call sites (21 sites, 11 files,
  `git status` agreed exactly at pass time); 0 binding literals moved, 0 `#undef` lines touched, 0 frozen
  banners edited (D39 precedent). Census post-pass: 600 / 119 / 479 / **0** / 2 - the checklist's predicted
  470 was a bucket-arithmetic mis-prediction; coverage stays **724**, bindings **599**.
- **Claims corrected in `registers/u17.md`, recorded not applied**: the population is **nine**, not eleven
  (D34's DDE delete took two); all 9 are defined and already bind AW with 0 bare bindings; the entry's
  525/108/404 census triple is not reproducible from any header in history.
- **The mirror set stays**: `CreateWindowT` binds the `CreateWindowEx` family and `CopyCursorT` binds bare
  `CopyIcon` - neither is an A/W family under its own stem, so both stay kind-5 deviations.
- Stale when an A/W-family member under its own stem loses the `T`, a binding literal gains a `T`, or the
  folder gate leaves exit 0 with 0 warnings.
