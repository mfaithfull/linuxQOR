# D45 - U26: the TCHAR width is an include-order property; notes land on the five published mirrors - POLICY (11 Nov 2026), CLOSES U26, NO CODE CHANGE

The decision, from `docs/agent/decisions/D45.md` (user, 11 Nov 2026): U26 closes in the D43 arm - **a note on each
published `winqor_gui` mirror the layer feeds**, then "cannot be fixed within `winqor_api_user`". Six comment
blocks over five headers, each naming the wrong shape or field, the feeding site, and the fix that belongs
elsewhere. **No token moved.**

- **The corruption instance**: `winuser.h` declares `ICONINFOEX` twice (A 560 bytes / W 1,080, arm picked by
  `UNICODE`/`_UNICODE`, whose only source in this tree is `kernel32.h:7-10` under `qor_pp_unicode`); the layer
  publishes `::PICONINFOEX` and pastes `GetIconInfoExW` **unconditionally**, so a narrow TU compiles the 560-byte
  shape against a 1,080-byte write at `icon.cpp:94` - 520 bytes past the caller's struct, no compile or link
  error. Note at `icon.h` above `IconInfoEx`.
- **The latent mirrors**: `ScrollInfo` (sound layout, but `nPos`/`nTrackPos` uninitialized while `SetScrollInfo`
  reads both), `WindowPlacement` (`length` uninitialized where the entry point requires `sizeof`), `Message`
  (ABI-correct on x64 only; `GetMessageT`/`PeekMessageT` write the caller's buffer), `MonitorEnumProc` (`long
  long` fourth parameter vs `LPARAM`), `MonitorInfoEx` (W-shape 104 bytes built, A-shape 72 in the narrow world -
  the `icon.cpp` overrun with roles reversed).
- **Why not here**: every wrapper already publishes the SDK prototype of the export it binds (D18); the payload
  types are `winqor_gui` published headers (`QOR_WINGUI`), so widening a field is another library's surface (U20).
  The layer-side half is settled: G1 include order, D13 spelling, D21 version pin - whose residual ("the pin does
  not constrain third-party consumers") stays recorded, and **no project-wide `/DUNICODE`** was added
  (`cmake/flags.cmake` re-reads 0 hits).
- Stale when one of the six notes disappears from the named header, a mirror field gains an initializer or
  changes width without a decision, or `flags.cmake` grows a `UNICODE` define contradicting "source property, not
  build setting".
