# D25 - T2: Desktop / Window Station callback parameters typed as the SDK's W spellings - ACTION (8 Nov 2026)

The decision, from `docs/agent/decisions/D25.md` (user decision, 8 Nov 2026): T2 closes by acting on
the one convention question it owns - `EnumDesktopsT` and `EnumWindowStationsT` take the SDK's **W**
callback spellings `DESKTOPENUMPROCW` / `WINSTAENUMPROCW` in place of the generic
`DESKTOPENUMPROC` / `WINSTAENUMPROC`, so the published parameter agrees with the entry point the
wrapper binds.

- Why this and not T2's other shapes: the section's deadness is D14's consumer-side territory, its
  U17 and P3 checks measured **conformant**, and its U2/U7 sites stay recorded-not-acted; the only
  open question is the typedef, and the SDK answers it - both wrappers bind `qor_pp_useswinapiAW`,
  so the entry point is always `...W`, and D18's "copy the prototype of the export it binds" names
  the W spelling (`WinUser.h:1480`/`:1610`; the generic names are one typedef hop away at `:201-202`).
- The edit is type-neutral and symbol-neutral: the generic names alias the W names in this header, so
  the two spellings are one type in this build - measured by compile-only `static_assert` probes
  (identity probes exit 0, an A-shaped callback and a `FARPROC` are each rejected); the probe files
  are throwaway, but the 6 edited sites (`user32.h:410`/`:413`, `desktop.cpp:86`/`:90`/`:107`/`:111`)
  live inside the gated TUs.
- It does **not** decide: U17's eleven unsuffixed A/W members and the two mirror cases stay deferred
  (the section was already 9/9 compliant); no published name moves, so it is not a rename; and the
  section's 18/18 deadness stays a `winqor_gui` question (D14).
- Recorded gate: `desktop.cpp` standalone at `/W4` exit 0, the 47-source folder gate exit 0 clean,
  `cl /EP` spelling the W typedefs at all six sites while the binding literals stay
  `"EnumDesktopsW"` / `"EnumWindowStationsW"`, and the 115-source all-libraries diff is **SHA-256
  identical** pre/post (`D286F848...96D6EAF`) - stronger than a set-difference. Counts unchanged:
  47 sources, 634 member-declaration lines, 759 covered.
