# D39 - U10: the console-internal surface is Microsoft-documented and the header block is verbatim - POLICY (10 Nov 2026), CLOSES U10, NO CODE CHANGE

The decision, from `docs/agent/decisions/D39.md` (user, 10 Nov 2026): the page
`learn.microsoft.com/windows/console/consolecontrol` **is** the authority U10 claimed absent; U10 closes on it
with **no code change** - the same made-behaviour closure shape as U7 (D35), U5 (D36) and U9.

- **Verbatim type block**: `user32.h:23`-`66`, whitespace-normalised, is case-sensitive-equal (`-ceq` True) to
  the page's six typedefs - 819 characters both sides, same order, same trailing comma; the `IN` SAL tokens at
  `:58`-`65` are Microsoft's own spelling, and the entry's probe (`tmp/_tmp_u10_cmp3.ps1` over a verbatim copy
  of the page's block) is the provenance of that comparison.
- **Signature mirrors the export** - `user32.h:814` matches the documented `ConsoleControl` exactly with SAL
  stripped; the only delta is the folder's own `static` convention (U4's census), verifying D18's rule for this
  member.
- **Export row**: `dumpbin /exports user32.dll` gives exactly one `ConsoleControl` row and no A/W pair, so the
  bare `qor_pp_useswinapi` at `console.cpp:39` (D13) is right; 5 commands pair 5 structures, 0 orphan; enum
  numbering is the documented implicit 0..7 and the `Reserved*` holes are Microsoft's names.
- **What the authority settles**: global-scope declarations are what the page prescribes ("must be declared by
  the caller", Header none / Library none), so U10 (i)-(iii) all fall; the no-import-library note is the
  Microsoft authority behind the `GetModuleHandle`+`GetProcAddress` design D36 accepted and the 0 import-lib
  entries in the `user`/`kernel` CMake link lines; the Windows 7 guard need is satisfied under the D21 pin.
- **Correction recorded, not applied**: the frozen review banner at `console.cpp:17`-`23` ("no Microsoft
  prototype ... export table is the only authority") is stale by D39 - protocol 7 leaves it in the TU. No src
  file changes; both gates stay at their D38 state.
- Stale when the documented block diverges from `user32.h:23`-`66`, a `ConsoleControlA`/`W` export appears, or
  the page contradicts the verbatim match.
