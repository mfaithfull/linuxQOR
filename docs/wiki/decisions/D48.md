# D48 - P6: the ANSI-alias trap population is 7 stems, all bound wide, so 0 live instances - POLICY (11 Nov 2026), CLOSES P6, NO CODE CHANGE

The decision, from `docs/agent/decisions/D48.md` (user, 11 Nov 2026): the P6 class - a bare stem exported as a
hidden alias of the ANSI entry point (bare row shares `<stem>A`'s RVA, `<stem>W` elsewhere), where a bare
binding **resolves and runs ANSI code on wide arguments silently** - closes as a **measured 0-instance close**:
the population is measured and liveness disproved in one pass.

- **Population 7, not the 2 the register knew**: `BroadcastSystemMessage`, `CallMsgFilter`, `GetAltTabInfo`,
  `GetWindowModuleFileName`, `IsDialogMessage`, `RealGetWindowClass`, `TranslateAccelerator` - each's three RVAs
  recorded; `IsDialogMessage` was flagged in `dialog.cpp`'s banner but never joined the item, four are new to
  the record.
- **All 7 bind `qor_pp_useswinapiAW`, 0 bare** - `accelerator.cpp:55`, `dialog.cpp:130`, `hook.cpp:82`,
  `message.cpp:108`, and three in `window.cpp` - the AW spelling fixes the literal by `##W` paste before any
  macro is consulted.
- **Even a bare spelling is disarmed**: `winuser.h` carries the `stem -> stemW`/`-> stemA` pair for all 7 and
  `user32.h`'s nine `#undef`s (`:13`-`21`) overlap the population **0 times**; the trap needs `!UNICODE` or an
  `#undef`'d stem, neither present.
- **Pitfall recorded**: the census regex must read the hint column as **hex** - a `\d+` filter silently drops
  `CallMsgFilter` (hinted `1C`/`1D`/`1E`), the register's own instance.
- **Residual**: the class stays a third-party hazard (a `!UNICODE` TU binding a bare stem hits the ANSI alias) -
  the D21/D45/D46 residual class; `registers/p6-u27.md` gains only its head closure line.
- Stale when the fresh export table grows an 8th such stem, any of the 7 gains a bare binding, or a population
  stem's `stemW` macro gains an `#undef` in `user32.h`.
