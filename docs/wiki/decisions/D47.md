# D47 - U20: the Cursor/Icon ownership notes move to the calling layers - POLICY (11 Nov 2026), CLOSES U20, NO CODE CHANGE

The decision, from `docs/agent/decisions/D47.md` (user, 11 Nov 2026): U20 lands as **a note on each calling
layer the item names** - nine comment blocks over eight `winqor_gui`/`winqor_wincommon` files (the `Cursor`/
`Icon` ctor defaults, `~Cursor`/`~Icon`, `Cursor::Show`, the four `ButtonController` sites, `WindowFactory`,
`WindowClass::SetIcon`, `PrimitiveHandle::~PrimitiveHandle`) - and closes as **cannot be fixed within
`winqor_api_user`**.

- **The taxonomy the notes carry**: a handle is a value, not an owner, and **the release verb is per family, not
  `Close`** - `CreateCursor`/`LoadCursorFromFileT`/`CopyCursorT` must see `DestroyCursor`, the `Create*Icon`
  family `DestroyIcon`; `LoadCursorT`/`LoadIconT` return shared OS-owned handles (measured: `LoadIconW(NULL,
  IDI_APPLICATION)` -> `0x1002B`, the same value every load); `CloseEnhMetaFile` **creates** and
  `ShutdownBlockReasonDestroy` destroys nothing.
- **Wrong decisions live at the call sites**: the `own = true` default on the published ctors, the four flagless
  `ButtonController` sites against `StaticController`'s `false`, the `WindowFactory` temporaries, the stored
  `WindowClass` handle that outlives its owner, `Clone()`'s `DestroyCursor(nullptr)`, `ShowCursor`'s signed count
  read as a flag; `PrimitiveHandle` has **no release/reset API**, so no consumer can clear before the destructor.
- **Why not here**: every named wrapper is a faithful pass-through (`DestroyCursor`/`DestroyIcon` forward
  verbatim); changing any decision is a behaviour change in another library (the U20 rule) - and a violated
  contract is often invisible (`DestroyIcon` on a shared handle returns 1 with `ERROR_INVALID_HANDLE`), which is
  why these findings were measured.
- **The rule keeps its name**: closing U20 does not retire the "U20 rule" other decisions cite - the notes move
  it into the sources it describes; D44 stays the only exception to it. `registers/u20.md` gains only its head
  closure line (protocol 7).
- Stale when one of the nine notes disappears from its named file, a ctor default flips, `PrimitiveHandle` grows
  a release/reset API, or the notes' cites are re-read as current line numbers.
