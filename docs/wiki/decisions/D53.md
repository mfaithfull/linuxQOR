# D53 - U2 small-TU code region: 124 sites over 33 TUs land from the table - CODE CHANGE (12 Nov 2026), U2 stays OPEN

The decision, from `docs/agent/decisions/D53.md` (12 Nov 2026): **the code side edits from the table, not
from the pages.** `SmallTUBatchRegionChecks` (S1-S5 -> 33 per-TU leaves, each at most 8 sites) walks the same
33 TUs U1's `BatchSmallTUs` batched, smallest first, applying each row's recorded verdict.

- **Measured**: small region 124 sites over 33 TUs = **79 checked / 42 unchecked / 3 void**; 5 rows were
  already decided (the D51 site plus four seeds) and were **not re-edited**, so **74 new tokens** landed;
  batch sites S1 10, S2 18, S3 27, S4 33, S5 36.
- **Edit shape**: `CheckReturn< sdkRetType, Check >::TType` at checked sites with the row's verbatim
  `docQuote` + class name in the site comment; the class base is the row's `sdkRetType`, never the published
  spelling (`LRESULT`/`LPARAM`/`HWND`/`AW` rows differ); one `../returncheck.h` include per TU that needed one.
- **Gate/census**: standalone `/W4` leg per batch TU-set exit 0 with objs newer than sources; per-TU
  re-census (`qor_pp_fcontext; == qor_pp_useswinapi* == Library::*Call< == Win32ErrorHandler _; == n`) at
  **fail=0 at every leaf**; after S5 the region reads **79 live `CheckReturn<` code sites over 28 of 33 TUs**
  (the 5 TUs with 0 checked rows take none).
- **Does not**: touch the 19 large-TU TUs or `accelerator.cpp` (D54's territory), run the folder gate
  (deferred to the close, as D50/D51 did), move any binding literal, member declaration or banner; `user32.h`
  and `returncheck.h` unchanged.
- Stale when a small-region site loses its token or reason comment, or a per-TU census equality breaks.
