# D24 - T6: the List Box trio wrapped in a new `listbox.cpp` TU, all three `static` - ACTION (8 Nov 2026)

The decision, from `docs/agent/decisions/D24.md` (user decision, 8 Nov 2026): **write the TU - three
wrappers in a new `listbox.cpp` - and make all three `static`.** Nothing is deleted. The whole
`//List Box functions` section (`user32.h:552-554`: `DlgDirList`, `DlgDirSelectEx`, `GetListBoxInfo`)
stood declared-non-static-and-undefined (U4 + U18) and was also the T3 shape - a whole section with
no owning TU.

- The two DlgDir members bind `qor_pp_useswinapiAW` for two independent reasons: their bare stems
  are not exported, and `user32.h:17-18` `#undef`s them, so the SDK's `-> W` macros are erased before
  the class is declared - a bare binding would stringize a name that does not exist and cache a NULL
  `pFunc` for the process lifetime (G2 + G5). `GetListBoxInfo` is a bare single export, so the bare
  macro is the D13 spelling there.
- Each signature copies the prototype of the export it binds (D18), and `DlgDirSelectEx`'s header
  declaration moves from the folder's parameter names to the SDK's (`hwndDlg`, `chCount`,
  `idListBox`) - names in a member declaration bind nothing, so that is readability, not ABI.
- What it settles: for the trio U4's link half and U18's non-static half are gone. U17 takes no
  action - the DlgDir pair are 2 of the eleven A/W members carrying no `T` suffix, and the
  session-11 defer policy holds the eleven until one folder-wide pass (after this TU 6 of the 11
  are defined). **Coverage does not move at 759 of 1,018**: all three were already declared - a link
  gap, never a coverage gap; the census reads static 545 -> 548 and bindings 544 -> 547 over 47 sources.
- Recorded gate: standalone `/W4` exit 0, folder 47/47 clean, `cl /EP` resolving the three literals
  against module literal `L"user32"`, and the shared-header diff 114 -> 115 cpp echoes, 165 warnings
  = 165, exit 2 both sides, set-difference 0 new / 0 gone - the corrected run, after a first attempt
  compiled a spurious `listbox.cpp.cpp` from a `.cpp`-terminated rsp path.
- Stale when `listbox.cpp` leaves the CMake source list or the `static` at `user32.h:552-554`
  disappears; the folder gate re-run falsifies it.
