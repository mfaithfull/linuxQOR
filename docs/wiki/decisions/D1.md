# D1 - Unit of work = one CMake library

The decision, from `docs/agent/decisions/D1.md`: the unit of work is one CMake library - a
`qor_` lib is shared, incremental-rebuildable, and matches ctags granularity.

- The entry's evidence was a `set(target qor_*)` scan finding **60 leaf libs**; that count is the
  artifact this decision sizes, and the wiki's own target list now prints 90 targets - a growth the
  entry's era could not have seen, so the page names the scan, not the number, as the thing to
  re-run.
- Everything downstream inherits the cut: `docs/agent/ctags/<lib>.tags` (D2), `cmake --build
  cmakebuild --target qor_X` (D3, and the wiki rule page
  `docs/wiki/invariants/build-commands.md`), and the one-page-per-target module layer.
- Stale when the library set changes shape (libs merged or split), which the same scan - or
  `wiki-census` against `repo_map.md` - shows.
