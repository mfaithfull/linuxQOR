# D36 - U5: the run-time binding cached in a function-local static const, a failed resolution included, is accepted as by design - POLICY (10 Nov 2026)

The decision, from `docs/agent/decisions/D36.md` (user decision, 10 Nov 2026): **accepted as by
design - no code change** - the same made-behaviour shape U1, U2, U7 (D35), U15 (D14), U16 (D21) and
U28 (D17) were closed on. The cache *is* the design; caching a failure with it is the same one-line
property, not an oversight.

- Measured basis: `kernel32.h:75` expands `qor_pp_useswinapi` so the entire resolution is the
  initialiser of a function-local `static const` - one `GetModuleHandle` + one `GetProcAddress` per
  wrapper for the process lifetime; the AW macro at `:77`/`:79` token-pastes into the same caching
  macro, so the AW path shares the property. The cached value is re-raised, not swallowed: `Call`,
  `voidCall` and `varCall` each test the `DefProc` for null and `throw("Missing library function.")`
  - a poisoned binding gives the **same** verdict on every later call, deterministic and observable
  (the bare `const char*` spelling stays U8's item).
- No import library pulls the modules in - the `user` and `kernel` CMake link lines carry 0
  `user32.lib`/`kernel32.lib` entries - so the layer's bindings are purely run-time, and the design
  assumption is the one the layer can only make: a wrapper is reached from a process with the Windows
  subsystem mapped. G5's bare-console NULL probe measures the alternative world, and this decision
  accepts it.
- Why it is wanted: over the folder's **599** bindings the cache is the difference between two loader
  lookups per wrapper for the lifetime versus two per call; and caching the failure keeps the verdict
  stable, where per-call re-resolution would make availability a race with module loading. The null
  binding throws before the `__try`, so D35's swallow path is never reached for this failure mode.
- What it does not do: `kernel32.h`/`library.h` untouched (the shared-header gate diff is not in
  play, no mangled name moves), U8/U2/U1 unchanged, and `registers/u5.md` frozen under protocol 7.
- Stale when the macro stops caching in a function-local `static const`, or a null binding stops
  throwing before the call.
