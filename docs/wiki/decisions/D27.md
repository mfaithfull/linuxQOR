# D27 - T9 step 9a: the 34 String functions wrapped in `strings.cpp`, `static` on all 34 declarations - ACTION (9 Nov 2026)

The decision, from `docs/agent/decisions/D27.md`: step 9a of the D26 tranche queue executed in D26's
own shape - one section, one new TU, one gate diff - with nothing re-derived: the 34 members of
`user32.h`'s `//String functions` section (`:342-375`), their ordinals, guards and prototypes were
measured once into a pre-table that is the source of every figure.

- New TU `src/platform/os/windows/api_layer/user/strings.cpp` defines **all 34**; `user32.h:342-375`
  gains `static` on all 34 declarations and nothing else - no type and no parameter name moves, so no
  mangled name moves and no caller follows; `CMakeLists.txt` goes 47 -> 48.
- Binding spelling: 34 bare `qor_pp_useswinapi`, **0** `qor_pp_useswinapiAW` - D13 seen from the other
  side: the members already carry the variant suffix, so the literal **is** the exported name and the
  AW macro, which pastes `Stem ## W`, would bind `CharLowerA` to the export `CharLowerW`; and
  `CharNextExA`/`CharPrevExA` have **no** `W` rows in the table at all, so there the AW form is not
  merely wrong but unavailable.
- Signatures follow D18 and needed no header work - all 34 were already spelled with the SDK's names,
  including the `OemToCharA/W` `__drv_preferredFunction` pass-through the SDK states and the SDK's
  buffer semantics. Availability: all 34 sit under `#ifndef NOUSER` with per-section family guards;
  D21's `0x0A00` pin makes the prototypes visible, while `NOUSER`/`NOLANGUAGE`/`NOAPISET` stay
  unpinned shrink macros - the half of U16 the pin did not close, recorded here.
- Census: static 548 -> 582, non-static 86 -> 52, bindings 547 -> 581 over 48 sources; **coverage
  stays 759 of 1,018** - the 34 were already declared, so 9a closes a link gap, never a coverage gap.
  Gate legs: standalone `/W4` exit 0, folder 48/48 clean, `/EP` 34 literals / 0 AW, and the
  all-libraries diff adds only the three new user TUs to the rsp, exit 2 both sides matching the
  standing baseline.
- Stale when `strings.cpp` leaves the source list or a later pass renames any of the 34 without
  U17's folder-wide pass having been done.
