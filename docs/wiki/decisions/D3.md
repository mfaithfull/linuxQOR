# D3 - Verification = compiler as judge

The decision, from `docs/agent/decisions/D3.md` (a user directive): verification is the compiler
as judge - `cmake --build --target qor_X` (incremental), recorded in `docs/agent/verification.md`.

- This is the ancestor of the wiki's whole build-judge layer: the rule page
  `docs/wiki/invariants/build-commands.md` and the 35 decision pages whose `Judges:` are recorded
  build lines all descend from it.
- The directive is not itself falsifiable against a build - it *creates* the thing that is - so it
  carries the D56 sentinel; falsification lives one level down, on the target builds it names.
- Stale when `docs/agent/verification.md`'s build section changes - its section is the anchor's
  neighbor, and `wiki-reconcile` history against this page's commit is the re-check.
