# QOR Repo Map

Generated by agent. Do not edit by hand; regenerate from CMakeLists.txt scan.

## Legend
- `L:` = library (SHARED unless noted)
- `D:` = directory containing the library
- `->` = target_link_libraries dependency edge (library depends on targets on right)

## Top-level src layout
- src/platform          qor_platform (L)
- src/framework         (structural libs)
- src/qor               (ubiquitous core libs)
- src/components        (apps/leaf libs; depended on, do not depend on other QOR libs)
- src/test, examples    (not libs)

## Subsystems (from docs/structure.md)
- components: extra libs not depended on by other qor libs (ui, protocols, io, data, qor)
- configuration, macros: not libs
- framework: structural elements (app/host/role/workflow/asyncio/pipeline/thread)
- platform: architecture / compiler / os (win/linux) adapters
- qor: assert, datastructures, factory, injection, instance, memory, mock, module, profiling, reference, sync, test
