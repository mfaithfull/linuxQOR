## D56: Wiki schema - a sentinel judge line for not-command-falsifiable pages; no instrument changes (18 Nov 2026)

Decision (user, 18 Nov 2026, asked at the `docs/future/BuildLLMWiki` ClaimCarryingPages pass): a wiki
page whose claim is **not falsifiable against a build** carries `Judges: none - <reason>` as its
single judge line instead of a command. The sentinel is honest, not a loophole: the required-field
rule (`WikiPageRequiredFields`, tools/wiki-census/wiki-shape.ps1:43) asks for a **non-empty**
`Judges:` list, and the sentinel names in its own reason why nothing can make the page red, which is
exactly what a judge line is for.

### Why (measured, the same day)

- The `DecisionPages` probe (`tmp/_tmp_dp_probe.ps1` -> `.txt`, 55 of 55 commit anchors green) found
  **20 of 55** D-entries name **no command at all** - policy and process verdicts (`D1`-`D8`,
  `D10`, `D11`, `D17`, `D33`, `D35`, `D36`, `D41`-`D45`, `D47`: ctags use, build layout,
  ignore-lists, accepted-as-is closings). A command cannot be written for them without inventing
  one, and inventing a judge is the one thing the wiki's falsification design forbids.
- The `Concept pages` item carried the same block from its creation (parent `ClaimCarryingPages`
  §Decisions: "concept pages carry no `Anchors:` and no `Judges:`" vs the required-field rule).

### The rule, for pages only - 0 instruments changed

- **Command-bearing pages are untouched**: module, gotcha, invariant, and the **35** decision pages
  whose D-entry records its own verification line keep real commands as judges.
- **Decision pages of command-less entries**: `Judges: none - policy verdict, no artifact
  (see docs/agent/decisions/D<n>.md)`. The reason names the verdict; the page's falsification is its
  commit anchor, read by `wiki-ref-check anchors` / `wiki-reconcile history` (dead on a moved
  path or absent sha).
- **Concept pages**: `Type: WikiPage`, `PageType: concept` (shipped vocabulary,
  wiki-shape.ps1:33 - the old prose `Type: wiki-concept` would have made the file a stray), the
  sentinel judge line, and the sentence the item already required: "this page describes a domain,
  not this tree; it is not falsifiable against a build".
- **No instrument edit and no freshness special case**: `wiki-lint schema` accepts the sentinel
  (the list is non-empty), and `wiki-lint freshness` leaves such pages `undated` by design, like the
  module pages already are - a page nothing dates is a page nothing can stale-date. The earlier
  measurement that `Test-WikiJudgeInVocabulary` is called by no shipped instrument stays as recorded
  in `docs/wiki/invariants/purpose.md`; correcting that prose assertion remains a governance edit
  outside this entry.
- **What would make the sentinel a lie**: any decision entry that **does** name a buildable artifact
  or command must use the real command - the sentinel is only for entries where a judge would have
  to be invented. The `DecisionPages` probe slot is the list of which is which.
