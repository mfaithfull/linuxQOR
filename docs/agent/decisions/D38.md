## D38: U8 - out-of-line null-binding report + explicit return - ACTION (10 Nov 2026), CLOSES U8 AND U29

The change (user, 10 Nov 2026, `src/platform/os/windows/api_layer/library.h`, one file, 1 member added + 3 sites): D37's `serious("Missing library function.")` written inline in each `__try` function (which read C2712 62 x / 126 x and broke the whole api_layer) is moved **out of line** and given an explicit return at the two value-returning sites.

`git diff` (5919be65 -> current, 1 file / 4 blocks):

- **New member at `library.h:30`-`33`:** `static void ReportMissingLibraryFunction() { serious("Missing library function."); }` - a class member defined in the class body, hence implicitly inline, so one definition per program and no ODR issue across the 122 sources; no wrapper signature changes and therefore **no published mangled name moves**.
- **`Call` at `:57`-`59`** (was `throw(...)`): `ReportMissingLibraryFunction(); ret _{}; return _;`

- **`varCall` at `:124`-`126`** (was `throw(...)`): `ReportMissingLibraryFunction(); ret _{}; return _;`
