## D53: U2 small-TU code region - the 124 sites over the 33 smallest TUs land from the table (12 Nov 2026)

Decision (12 Nov 2026): **the code side edits from the table, not from the pages.** `SmallTUBatchRegionChecks` (5 `Refined`
items S1-S5 -> 33 per-TU `Atomic` leaves, each at most 8 sites) walks the same 33 TUs U1's `BatchSmallTUs` batched, smallest
first, and at each site applies the recorded verdict: land `CheckReturn< sdkRetType, Check >::TType`, keep the published
contract, and put the row's verbatim `docQuote` plus the class name in the site comment.

### Measured

- Small region **124** sites over **33** TUs: **79 checked / 42 unchecked / 3 void** (sum 124). Of the 79 checked rows,
  **5 were already decided** (`errorhandling.cpp:85`, `processthread.cpp:87`/`:97`/`:115`, `systemshutdown.cpp:134` - D51's
  site) and were **not re-edited**, so **74 new tokens** landed here.
- Batch sites: S1 10 (8 checked), S2 18 (13), S3 27 (12 checked incl. 1 seed), S4 33 (12), S5 36 (34).
- Every one of the 42 unchecked rows carries its written reason at the site (answer-shaped `BOOL`, zero-is-legal count,
  previous-state return), and the 3 `void` rows take no token (`Library::voidCall` shape).
- The class base is the row's `sdkRetType`, never the published spelling - `LRESULT`/`LPARAM`/`HWND`/`AW` rows are the
  cases where the two differ.

### Gate and census per batch

- Standalone `/W4` leg per batch TU-set: exit 0, 0 diagnostics, objs newer than sources
  (`tmp/_tmp_u2_gate_tus.ps1` -> `tmp/_tmp_u2_gate_tus.out.txt` `tus=n fail=0`).
- Per-TU re-census per leaf (`tmp/_tmp_u2_code_census.ps1`): `qor_pp_fcontext; == qor_pp_useswinapi* == Library::*Call< ==
  Win32ErrorHandler _; == n` with `CheckReturn<` code sites counted separately against the row count - **fail=0** at every
  leaf; one `../returncheck.h` include added per TU that needed one.
- Layer-wide live `CheckReturn<` code sites after S5: **79 over 28 of the 33 TUs** (the 5 already-decided seeds plus the
  74 new tokens; the 5 TUs with 0 checked rows - `brush`, `console`, `ime`, `text`, `windowprocedure` - take none). The
  folder-wide census at the close reads 352 over 48 TUs (D55).

### What D53 deliberately does not do

- Does not touch the 19 large-TU TUs or `accelerator.cpp` (D54's territory) and does not run the folder gate - the
  folder-wide 54/54 gate is deferred to the close, as D50 and D51 did.
- Re-edits none of the 5 already-decided seeds, moves no binding literal, no member declaration, no banner;
  `user32.h` and `returncheck.h` unchanged.
- Leaves the 42 unchecked sites exactly as they were apart from the comment - no behaviour change there.
